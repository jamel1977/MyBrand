MyBrand Website est un site web responsive développé avec HTML5, CSS3 , Bootstrap 5 et JS.  
## Fonctionnalités
- Barre de navigation responsive avec menu burger
- Section d’accueil moderne (Hero/Header)
- Présentation des services sous forme de cards
- Carousel Bootstrap interactif
- Logos des clients/partenaires
- Design responsive pour ordinateur, tablette et smartphone
- Utilisation des icônes Bootstrap Icons
- Intégration de Google Fonts


MyBrand Website is a responsive website developed using HTML5, CSS3, Bootstrap 5, and JavaScript.

## Features
- Responsive navigation bar with burger menu
- Modern hero/header section
- Services presentation using cards
- Interactive Bootstrap carousel
- Clients/partners logos section
- Responsive design for desktop, tablet, and smartphone
- Use of Bootstrap Icons
- Integration of Google Fonts
